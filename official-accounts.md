### Mortgage NFT Collection

The Mortgage NFT Collection, Stable Home Debt NFTs, are the mortgages that back USDX. Each Stable Home Debt NFT represents a single real estate–backed loan (mortgage) issued and/or tokenized by Stable, and linked to the property held in its corresponding Stable Home Account.

#### Specific to the Solana Deployment

On Solana, the collection is a Metaplex Certified Collection, so every member NFT is verified on-chain against the collection address and cannot claim membership without being signed for by the collection authority. Individual NFTs are derived as PDAs of the USDX Token Program. Members are enumerable programmatically via the Metaplex Digital Asset Standard (DAS) API — `getAssetsByGroup` with the collection address — or by viewing the collection on Solscan or Magic Eden.

## Stable Points

[Stable Points](https://app.trystable.co/points) (SP or points) are a way for users to be recognized for participating in Stable's ecosystem. There are a number of ways to earn points, each of which is listed below with an outline of how many points can be expected and notes that include working examples. You can read more about Stable's [Points Program on Medium](https://medium.com/stable-inc/why-we-built-the-stable-points-program-b0398141c0ff).

| Task                     | Applies To                | Reward                                                                    | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------------ | ------------------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mint                     | USDX, mUSDX, EURX         | 1 point per 1 token                                                       | Example: Minting 100,000 USDX earns 100,000 points.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Refer                    | All actions               | 10% of referred user's points                                             | <p>Referrers earn 10% of all points earned by any user referred.</p><p>Example: If a referred user has earned 100,000 points, then the user who referred them will have earned 10,000 points.</p><p>Example: If a referred user is earning 10,000 points per day, then the user who referred them is earning 1,000 points per day for as long as that continues.</p><p>Referrals are locked in when a referred user mints USDX from a referral link.</p>                                                                                 |
| Hold                     | USDX, mUSDX, EURX         | 10% per $1 per day                                                        | Example: Holding 100,000 USDX earns 10,000 points per day.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Swap                     | USDX, mUSDX, EURX, STABLE | 1% per $1 of volume                                                       | <p>Example: If SOL = $150, a 10 SOL swap to USDX, mUSDX, EURX, or STABLE earns 15 points.</p><p>Swap volume must route through one of the <a href="official-accounts.md#stable-points-for-trading-and-liquidity">qualified pools (listed below)</a> to earn points.</p>                                                                                                                                                                                                                                                                  |
| Liquidity Provision (LP) | USDX, mUSDX, EURX         | 1 point per $1 per day                                                    | <p>Example: An LP position of 100 USDX and 100 USDC earns 200 points per day.</p><p>Example: An LP position of 1 SOL and 100 USDX, if 1 SOL = $150, earns 250 points per day.</p><p>LP positions must be to one of the <a href="official-accounts.md#stable-points-for-trading-and-liquidity">qualified pools (listed below)</a> to earn points.</p>                                                                                                                                                                                     |
| (BONUS) Hold STABLE      | All points                | <p>2x multiplier on all points</p><p>1% per $1 of STABLE held per day</p> | <p>Holding >= 100,000 STABLE adds a 2x multiplier to add points earned.</p><p>Example: A user earning 10,000 points per day who also holds 500,000 STABLE earns 20,000 points per day</p><p>Additionally, holding STABLE earns 1% per $1 of STABLE per day.
