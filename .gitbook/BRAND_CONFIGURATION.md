# Stable Docs — GitBook theme configuration

GitBook stores site-wide visual settings outside the Git Sync repository. Apply the following settings in **Site → Customization** to align the published docs with the Stable landing page.

## General

- Site title: `STABLE DOCS`
- Default mode: Light
- Theme: Clean
- Primary color: `#B38533`
- Tint color: `#3A2A17`
- Corners: Straight
- Depth: Flat
- Links: Accent
- Icons: Regular
- Sidebar background: Filled
- Sidebar list: Line

## Typography

- Standard font: Manrope when custom fonts are available; otherwise use the closest neutral grotesk available in GitBook.
- Monospace font: Fira Code.
- Use sentence case for page titles and uppercase only for short navigation or status labels.

## Header

- Logo/title link: `https://trystable.co`
- Link: Reserves → `https://trystable.co/reserves`
- Link: Whitepaper → `/usdx-whitepaper`
- Link: X → `https://x.com/trystable`
- Primary button: Open App → `https://app.trystable.co`

## Footer

- Copyright: `Stable Finance`
- Links: Website, Reserves, Official Accounts, Terms, Privacy

GitBook does not support repository-provided custom CSS or JavaScript. Keep visual changes within GitBook's customization system and the content blocks committed in this repository.
