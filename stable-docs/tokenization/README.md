# Tokenization

## Originate, finance, and manage real estate debt onchain

Stable provides institutions with infrastructure to tokenize mortgage and real estate assets without replacing the systems and counterparties they already use. The workflow connects verified asset data, legal documentation, servicing, and onchain ownership.
