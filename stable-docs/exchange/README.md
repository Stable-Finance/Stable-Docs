# Exchange

## Overview

Starting with mortgages and real estate, Stable is building an exchange for tokenized institutional assets and structured products. This exchange helps increase the liquidity of institutional products onchain both for institutional and retail use.

This exchange has the potential to change capital markets in a number of ways, for example, a homeowner could purchase their own mortgage, or trade a fraction of their home equity for Bitcoin.
